# My Kit


## My Kit
Who doesn't like random pictures of geek pr0n? Here's a small selection of random crap as I deem it interesting

![MainServers2](/wiki-media/MainServers2.JPG)

My two main servers (hosting various sites or development code). 
The 1U is a Dell 860 Quad Core Xeon with 8Gig of ECC DDR2. It's currently running VMWare ESXi with a variety of nodes (The two windows nodes eat the majority of the memory). 
The second machine is a custom half U (1/4?) Atom 230 machine with 2Gig of ECC DDR2. This is mostly used as a NAS, mostly backups and a couple of monitoring services. I'm a big fan of Debian (and Ubuntu) so that's what it's running. In the cupboard are a number of external hard disks. I chose to use external disks just in case a machine goes up in smoke - I'd rather them operate independently. Sadly it does mean it eats CPU cycles if you're running any heavy I/O.

![MainServers](/wiki-media/MainServers.JPG)

As you can guess, both machines are sitting in my kitchen! A little hazardous but they've been running happily undisturbed for a year now. If it ever gets host it doesn't take long to find out, those servers spin up their fans louder than any hair dryer I've heard!

![SecondaryServer](/wiki-media/SecondaryServer.JPG)

This is my old dedicated server. Unlike my new machines this is just a standard desktop build which nothing overly special. 2.6 Athlon XP (Thoroughbred if I recall correctly), 4gig of RAM. Strangely despite being really bloody old it's run flawlessly for years and years. While I was away at Uni it happily ran unattended in a shed for well over a year. It along with several other boxes have been decommissioned in the name of the environment. This box is now virtualised on ESXi.

![SecondaryServer2](/wiki-media/SecondaryServer2.JPG)

Ah this machine was dumped with my after it was supposedly knackered (almost new!). A relatively sprightly machine clocking in a 3.2 (P4 65nm iirc?). A quick spit and polish (like a RAID array and 4gig DDR1) and she was up and running again. Used fairly recently as a database server for the folding@home statistics. Decided to decommission it as I didn't trust the PSU and it ran bloody hot - even with a U120 stuck to it!
