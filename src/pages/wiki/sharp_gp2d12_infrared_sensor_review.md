## Introduction
The Sharp GP2D12 is an exceptionally easy to use sensor for beginners. Unlike more expensive sensors like the URM37, it provides a continuous stream of analogue data you use to guide a robot to safety.

## Applications
I would suggest the GP2D12 for use as an auxiliary sensor. Unlike the URM37, infrared operates at the speed of light (surprise!) which means it’s great for providing continual feedback to your MCU. I use it to adjust and refine the robots position whilst using more accurate sensors to avoid “harder to see” obstacles. 
I would avoid using the GP2D12 as a primary source of distance information as it is easily affected by different materials. A shiny cupboard for example will throw the sensor entirely off.

## Summary
Overall this sensor adds great value to an existing project and it’s surprisingly small form-factor (about the size of an AA battery) great for slapping them where other sensors cannot go! It ‘s particularly well suited for new robot builders as it’s very simple to use and is only limited by the number of analogue inputs you have.
