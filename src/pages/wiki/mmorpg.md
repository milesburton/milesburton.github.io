## Thoughts on MMOPRG game
- Dynamic Agent Driven 'Factions'
- Various towns with 'real' people in them. The people should respond to the player based on 'Kindness' and 'Evil' (Think Black & White)
- Evil Factions would evolve and attack good factions based on a set of criteria (location, time of day, season, 'anger', 'enemy of the wilds')
- You could hire mercenaries or gain enough positive karma to recruit townsfolk (and various agent adventurers)
- Characters should act independently (Again, AI System Agents) based on a number of factors. Strength, Stamina, 'Confidence' (Fear, party strength)
  - Characters have their own Agenda's (To gain gold, magic, weapons.. buy/sell stuff to market etc). Will backstab or fight depending on their loyalties
- A user (or scripted ally agent) can mine areas (Think minecraft random reward). Again, characters may be territorial. Will need to avoid a user from destroying a landscape. Maybe allow the 'wilds' to restore it?
- Try and introduce a real-time element. That said, none of those "wait two days to train" crap (cough, eve online). You should earn any upgrades
- Community should be able to gather resources and build their own houses/towns. This also includes agents. Agents would attempt to build new towns based on criteria (water, resources, safety, alliances)
  - Enemies would attempt to destroy 'towns'. If they lost they would try and counter with the appropriate force (Siege weapons, alliances with mages). They would be bound by the same time/resource limitations as the player
- Some sort of player mounts/companions with their own set of stats (personality, agenda yada yada)

## Mini games
- There should be various mini games. Little arcades which earn money, dexterity etc
- Gambling could be an interesting side effect. A game where a rich user provides a bounty (which is paid out via a dispenser). Another could gamble Black Jack?
- Auction house. This goes without saying. Agents could come into play on this, if the house has a demand for certain merchandise agents could go out hunting to sell.

## Environment
- The environment should be partially procedurally generated but with key areas in keeping with the storyline. - For example, No one cares whats between Isenguard and helms deep providing it's in keeping with the tone (areas could have stats. Evil, magic, Dark magic,

## Setting
- Fantasy, obviously
- Magic, who doesn't like magic?

## USP
- Scriping would be essential. You should be able to script various elements of the game (And buy scripts). For example, you could hire a 'programmable' mercenary to survey the nearby area looking for gold (mapping).
  - Mercenaries could perform tasks such as using tools to build axes in response to other players
  - Mercenaries could shadow a player and attack enemies
- Programmable environment
  - You should be able to program certain 'computers. that have components. Taking the arcade example you could create a roulette game which had a number of components (a gold coin slot, a button etc) and then would perform actions appropriately.

## Technology
- JavaScript seems like a good bet. Making use of Websockets, NodeJS. HTML5 (potentially canvas)
- Agents should be powered by client browsers and servers. (A agent action should be processed by multiple clients. The most common result would be commited to the game world')
