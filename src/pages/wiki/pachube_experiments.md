## Introduction
Pachube is an online page which lets you upload various metrics so you can build historical graphs. What's great about Pachube is it's all free and uses some very basic APIs which makes it perfect to cook up simple but interesting projects.

## Projects
**Temperature Monitoring**
Hardware: An AtMega328 (Arduino) coupled with a WiShield WiFi peripheral
Monitor: Maxim DS delivery
Library: TCL 3.5 

This monitor is setup to monitor the temperature of a home server bay. You can check out the historical graph [here](http://www.pachube.com/feeds/6645/datastreams/0/history.png) and view the full history on [Pachube](http://www.pachube.com/feeds/6645)
