# NZB Air Web Service - Release 3

<p class="wiki-date">Earliest known revision <time datetime="2012-04-14T15:20:41Z">14 Apr 2012</time></p>


## Release 3
Release 3 is intended to be a follow HATEOS compliant web-service. Rather than provide a one dimensional list of provider content it will focus around entries and next media types. Any type of content will appear in a feed and it is up to the client to interpret the type and how to manage the next links.
