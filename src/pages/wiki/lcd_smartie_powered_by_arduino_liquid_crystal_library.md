## Introduction
This library allows you to use the inbuilt Liquid Crystal library on Arduino IDE 0017 (and potentially further iterations) with the fantastic, if a little clunky, LCD Smartie application. You can buy an LCD Smartie compatible LCD from MnetHardware. They have both the [20x4](http://www.mnethardware.co.uk/displays/character-lcds/20x4-blue-backlit-lcd-with-hd44780-controller) and [16x2](http://www.mnethardware.co.uk/displays/character-lcds/16x2-blue-backlit-lcd-with-hd44780-controller) models

### What is LCD Smartie?
*LCD Smartie is open-source software for Microsoft Windows which allows an LCD display to be used as a (additional) display device for a PC. Supported devices include the Hitachi HD44780 Controller, the Matrix Orbital Serial/USB LCD, and Palm OS devices (when used in conjunction with PalmOrb).*

*The project was started as freeware by Basie P who wrote it in delphi. After a long period running the software as a freeware, from 2001 to late 2004, Basie P quit the project and it is now maintained as an open-source project by Chris Lansley.*
