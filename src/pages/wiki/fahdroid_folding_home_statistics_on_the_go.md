## Folding@Home Statistics for Android
FAHDroid brings the latest Folding@Home statistics straight to your phone courtesy of the [Razer Statistics](http://stats.mnetcs.com).

### Features:
- View team & user listings with associated ranks, points and users
- Order by almost any field
- See the latest user details with points production graphs
- Add a home screen widget for your favourite user

## Comments from the developer:
Enjoy the very first release of FAHDroid on the market (and very possibly the first folding@home statistics app!). 

The feature list will grow over the coming months so be sure to keep an eye out for the latest updates and bug fixes. 

If you spot any errors or better yet, have some great suggestions please drop me an email.
