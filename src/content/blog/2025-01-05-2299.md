<h3 class="wp-block-heading">Understanding Your Hardware</h3>



<p class="wp-block-paragraph">The Raspberry Pi Pico is powerful but has limited memory, so we need to be mindful of how we use it. Instead of storing the entire screen’s pixels in memory, we’ll generate our animations on the fly. This approach ensures smooth performance without overloading the microcontroller.</p>



<h3 class="wp-block-heading">Step-by-Step: Building Pong</h3>



<p class="wp-block-paragraph">Let’s break the game down into simple, manageable steps so you can see how it all fits together.</p>



<h4 class="wp-block-heading">Step 1: Setting Up the Display</h4>



<p class="wp-block-paragraph">First, we need to initialise the RGB LED panel so it’s ready for drawing. Here’s how:</p>


<div class="wp-block-syntaxhighlighter-code "><pre class="brush: python; title: ; notranslate" title="">
import hub75

# Set up the panel dimensions
PANEL_WIDTH = 64
PANEL_HEIGHT = 32

# Initialise the panel
panel = hub75.Hub75(PANEL_WIDTH, PANEL_HEIGHT, stb_invert=False)
panel.start()
print("Display initialised.")

</pre></div>


<p class="wp-block-paragraph">This sets up the LED panel and prepares it for our game.</p>



<h4 class="wp-block-heading">Step 2: Defining the Game State</h4>



<p class="wp-block-paragraph">To keep track of the paddles and the ball, we need a class to manage the game’s state. Here’s how we define it:</p>


<div class="wp-block-syntaxhighlighter-code "><pre class="brush: python; title: ; notranslate" title="">
import random

class GameState:
    def __init__(self):
        self.paddle1_y = (PANEL_HEIGHT - 8) // 2
        self.paddle2_y = (PANEL_HEIGHT - 8) // 2
        self.paddle1_x = 2
        self.paddle2_x = PANEL_WIDTH - 4
        self.reset_ball()

    def reset_ball(self):
        self.ball_x = PANEL_WIDTH // 2
        self.ball_y = PANEL_HEIGHT // 2
        self.ball_dx = 1.5 if random.random() &gt; 0.5 else -1.5
        self.ball_dy = random.uniform(-0.8, 0.8)

</pre></div>


<p class="wp-block-paragraph">This class makes it easy to reset the ball and update paddle positions as the game progresses.</p>



<h4 class="wp-block-heading">Step 3: Drawing the Game Objects</h4>



<p class="wp-block-paragraph">Now we need to create functions to draw the paddles and the ball on the LED panel:</p>


<div class="wp-block-syntaxhighlighter-code "><pre class="brush: python; title: ; notranslate" title="">
def draw_paddle(panel, x, y):
    for i in range(8):
        for j in range(2):
            panel.set_pixel(x + j, int(y) + i, 255, 255, 255)  # White paddle

def draw_ball(panel, x, y):
    for i in range(2):
        for j in range(2):
            panel.set_pixel(int(x) + j, int(y) + i, 255, 255, 0)  # Yellow ball

</pre></div>


<h4 class="wp-block-heading">Step 4: Animating the Ball and Handling Collisions</h4>



<p class="wp-block-paragraph">The ball needs to move and bounce off the walls and paddles. Here’s how we handle that:</p>


<div class="wp-block-syntaxhighlighter-code "><pre class="brush: python; title: ; notranslate" title="">
def check_collisions(game_state):
    if game_state.ball_y &lt;= 0 or game_state.ball_y &gt;= PANEL_HEIGHT - 2:
        game_state.ball_dy *= -1  # Bounce off top and bottom walls

    if game_state.ball_x &lt;= 0 or game_state.ball_x &gt;= PANEL_WIDTH - 2:
        game_state.reset_ball()

</pre></div>


<h4 class="wp-block-heading">Step 5: Putting It All Together</h4>



<p class="wp-block-paragraph">The main game loop combines everything and keeps the game running:</p>


<div class="wp-block-syntaxhighlighter-code "><pre class="brush: python; title: ; notranslate" title="">
import asyncio

async def game_loop(panel):
    game_state = GameState()

    while True:
        game_state.ball_x += game_state.ball_dx
        game_state.ball_y += game_state.ball_dy

        check_collisions(game_state)

        panel.clear()
        draw_paddle(panel, game_state.paddle1_x, game_state.paddle1_y)
        draw_paddle(panel, game_state.paddle2_x, game_state.paddle2_y)
        draw_ball(panel, game_state.ball_x, game_state.ball_y)
        panel.update(panel)

        await asyncio.sleep(0.05)

</pre></div>
