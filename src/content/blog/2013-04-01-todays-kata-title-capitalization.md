<blockquote>
<p>Title Capitialization</p>
<p>Many writers are often confused by the different methods of capitalizing titles. There are several forms of capitalization rules, but one of the most popular is called &#8220;title case&#8221; or &#8220;up style.&#8221; Implement a function that will take a title in the form of a string and return the string with the correct capitalization for the title according to these rules.#</p>
<p>* Always capitalize the first word in a title<br />Always capitalize the last word in a title.<br />Lowercase the following words, unless they are the first or last word of the title: &#8220;a&#8221;, &#8220;the&#8221;, &#8220;to&#8221;, &#8220;at&#8221;, &#8220;in&#8221;, &#8220;with&#8221;, &#8220;and&#8221;, &#8220;but&#8221;, &#8220;or.&#8221;<br />Uppercase any words no in the list above.<br />(This is not the exact set of rules, but pretty close)</p>
<p>A word is defined as a series of non-space characters</p>
<p>Example 1: &#8220;i love solving problems and it is fun&#8221;<br />Would return, &#8220;I Love Solving Problems and It Is FuN&#8221;</p>
<p>Example 2: &#8220;wHy DoeS A biRd Fly?&#8221;<br />Would return &#8220;Why Does a Bird Fly?&#8221;</p>
</blockquote>
<p>Tips:</p>
<ul>
<li>Think BDD</li>
<li>Simplest possible solution first (for each Red, Green, Refactor cycle)</li>
<li>What are the assumptions you are making? Assumptions are fine assuming the tests state how the implementation should be used</li>
</ul>
