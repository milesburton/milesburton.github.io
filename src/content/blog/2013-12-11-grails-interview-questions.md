<p>Grails is a real pleasure after working with Java for many years. Although lots of development shops have started introducing Groovy and/or Grails into they development stack there isn&#8217;t reall much in the way of guidance of what to learn and how a hypothetical interview may progress. I&#8217;m not entirely sure what a Senior Developer or Technical Lead is these days however I&#8217;ve always tried to do my best to hire the best people for the business. Below is a bunch of questions I&#8217;ve aggregated from my personal experience and a few that I thought were knowing (consider it a pop quiz!)</p>
<ol>
<li>You&#8217;re building a domain model which will be persisted to a hibernate backed data store? Can you recommend a way to efficiently test your relations work correctly?</li>
<li>How does grails support transactions?</li>
<li>How do you create a custom spring bean within grails?</li>
<li>I&#8217;d like to create my own Java Bean, what approaches could I take to make Grails and by proxy, Spring aware?</li>
<li>Having different URL mappings per environment can be really useful, how could I specify, say, a custom 500 for development purposes?</li>
<li>Can you provide a brief description of how Groovy applies AOP?</li>
<li>What is the Expandometaclass? Would it make your development process more or less flexible? How so?</li>
<li>Scaffolding, what is it, how do you use it? how would you change it?</li>
<li>Can you explain Active Record? Explain your experiences, both positive and negative. (Think DDD, boundaries, coupling, Ask-Dont-Tell etc)</li>
<li>The GORM is a great idea but can you think if instances when you shouldn&#8217;t or couldn&#8217;t use it? What would you use instead?</li>
<li>What is a Hibernate projection? Why would you use it? How is that achieved through the GORM?</li>
<li>Grails has a thriving ecosystem of plugins within the community &#8211; how would you decide whether a plugin was good?</li>
<li>If you were to write the Grails Plugin system all over again, how would you improve it?</li>
<li>Let&#8217;s say you&#8217;ve built a web page that lists the latest football scores from a database. In your experience can you tell me how you&#8217;ve diagnosed a performance problem?</li>
<li>Grails is great but what other frameworks and languages are out there. If you were working for $X what constraints do you foresee and how would that effect your framework choice?</li>
<li>How does Grails support internationalisation??</li>
<li>What techniques does Grails use to mitigate against XSS attacks?</li>
<li>Is it possible implement different sitemesh layouts?</li>
<li>What is the drawback of using a template rather than a view when rendering from a controller?</li>
</ol>
